# lazy_scripts

Random scripts I vibe coded while doing CTFs/labs

| Script | Purpose |
|---|---|
| `ip-a.sh` | Displays network interface information when the `ip` command is unavailable. Basically an `ip a` knockoff. |
| `mimikatzparser.sh` | Extracts usernames, passwords, NTLM hashes, and credential pairs from Mimikatz output. |
| `nmapparser.sh` | Converts standard Nmap output into a compact Markdown table of hosts and open ports. |
| `pspy_buddy.sh` | Searches logs and common system locations for commands observed through pspy. |

## Usage

Usage examples and notes are included at the top of each script.
